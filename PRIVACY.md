# Privacy

Jira Ticket – Copy as Markdown is maintained by inndevs. Updated November 5, 2026.

Opening the extension reads the current Jira issue and copies Markdown. Data includes the issue URL, title, description, fields, comments, names, and attachment links. Issue content may contain personal information. Export options affect the output; available issue data is read regardless of those options.

Requests go to the current HTTPS Jira site using your existing session. The extension does not read or store passwords, tokens, or cookies. If the API fails, it reads visible issue content. It does not access browser history or monitor other tabs.

Issue data is processed in memory and copied to your operating system clipboard. Only export preferences are saved in Chrome's local extension storage. Attachment files are not downloaded. There are no developer servers, analytics, advertising, background collection, or data sales. Issue content is not sent to inndevs or third-party services.

Clipboard contents follow your operating system's retention, history, synchronization, and application-access settings. Clear them through those controls. Uninstalling removes saved preferences, but does not remove pasted copies or change Jira data.

The extension's use of user data complies with the Chrome Web Store User Data Policy, including Limited Use requirements.

[Contact and support](https://github.com/inndevs/jira-ticket-copy-as-markdown/issues). Issues are public; do not post private content or credentials.
